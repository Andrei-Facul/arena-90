Sobre o ARENA 90

O ARENA 90 é um portal esportivo desenvolvido para reunir conteúdos sobre futebol, basquete e Fórmula 1 em um ambiente organizado, acessível e responsivo.

O portal oferece matérias temáticas, notícias com fontes identificadas e links para leitura aprofundada. Também apresenta uma classificação de pilotos da Fórmula 1 obtida através de uma API externa.

Nosso objetivo é combinar informação esportiva, navegação intuitiva e tecnologias de desenvolvimento web em um projeto acadêmico funcional.

Conheça nosso portal

Nossa Missão

Facilitar o acesso a conteúdos esportivos, permitindo que o visitante explore matérias, conheça diferentes modalidades e consulte fontes originais.

Conteúdo Esportivo

O ARENA 90 reúne matérias de futebol, basquete e Fórmula 1, além de uma edição de notícias com datas e fontes identificadas.

Tecnologias Utilizadas

HTML5 para estrutura e semântica, CSS3 para apresentação, Flexbox e Grid para layout, e JavaScript para integração com serviços externos.

A classificação de pilotos é consultada através da Jolpica F1 API, utilizando fetch() e dados em JSON.

Projeto Acadêmico

Desenvolvido como trabalho da disciplina de Programação Web Coding do curso de Ciências da Computação.

O projeto aplica HTML semântico, metodologia BEM, responsividade, interatividade, acessibilidade e consumo de uma API externa.

Fontes e atualização

As matérias temáticas direcionam o visitante para conteúdos publicados por organizações esportivas e veículos de comunicação.

A seção Notícias do Dia apresenta uma seleção editorial com data identificada. Suas manchetes são inseridas manualmente e não são atualizadas em tempo real.

Já o painel de classificação da Fórmula 1 consulta informações da Jolpica F1 API pela internet. Se o serviço estiver indisponível, o restante do portal continuará funcionando normalmente.
